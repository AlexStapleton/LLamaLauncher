Model size affects both weight memory and loading time. KV cache and working buffers need additional memory.

What changes speed and memory?

GPU layers

More offload usually means faster inference and more VRAM for weights.

Context size

Longer context needs more KV cache and can slow attention processing.

Batch size

Larger batches can improve prompt throughput but need larger working buffers.

Cache precision

Quantized KV caches use less memory; speed and quality depend on your backend and model.

Descriptions come from your executable. Performance guidance is qualitative: hardware, quantization and workload determine the actual result.
