Model size affects both weight memory and loading time. KV cache and working buffers need additional memory.

What changes speed and memory?

GPU weight layers · Settings → GPU

More layers move weights and work to GPU, using more VRAM. Twice the layers does not guarantee twice the speed.

Context · Settings → Context & cache

4096 → 8192 tokens roughly doubles dense KV capacity; model weights stay the same. Longer attention can slow generation.

Batches · Settings → Performance

Larger physical batches need more working buffers and may help prompt throughput. They do not guarantee faster single-token generation.

Cache precision · Settings → Context & cache

f16 → q8_0 uses roughly 53% of each changed cache component's raw storage, before overhead. Quality and speed depend on the backend/model.
